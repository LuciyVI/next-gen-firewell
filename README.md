# Packet Control · NGFW Simulator

Учебная браузерная игра об операторе NGFW в визуальном стиле UserGate: тёмная панель, оранжевые акценты, схема прохождения трафика и рабочее место анализа пакетов. Неофициальный учебный проект.

## Запуск

Требуется Node.js 22.12+ (проверено на 24.19.0).

```sh
npm ci --cache /workspace/.npm-cache
npm run dev -- --port 5173
```

При обычной локальной установке можно использовать `npm ci` без параметра кеша. В облачной среде кеш вынесен в доступный для записи каталог.

```sh
npm test          # тесты правил игры
npm run build     # TypeScript + production-сборка в dist/
npm run preview   # запуск собранного приложения
```

Браузерная проверка требует запущенного dev-сервера и Chromium:

```sh
npm run test:e2e
# При необходимости переопределите пути:
CHROMIUM_PATH=/path/to/chromium E2E_BASE_URL=http://127.0.0.1:5173 npm run test:e2e
```

### Автономная версия

```sh
npm run build:standalone
npm run test:standalone
```

Файл `dist/packet-control.html` содержит игру, стили, значки и логотип. Его можно переносить отдельно от проекта; runtime не требует CDN или внешних API. Браузерный тест проверяет эту сборку без сети. Прямая навигация `file://` в управляемом Chromium среды запрещена его политикой; здесь автономный документ проверяется в offline-контексте через загрузку HTML в страницу. Открытие файла двойным щелчком за пределами среды отдельно не проверялось.

Приложение работает целиком в браузере. Сервисы, API-ключи и базы данных не нужны. Production-результат — статическая папка `dist/`.

## Механика

- Смена состоит из 24 подготовленных сценариев: 12 нормальных и 12 вредоносных.
- Игрок изучает метаданные сеанса, выбирает FastPath или Полная проверка, затем разрешает или блокирует пакет.
- FastPath допускается для проверенного сеанса, которому не требуется СОВ/L7-инспекция. Фрагментированные пакеты в FastPath не обрабатываются. Установленный сеанс с требованием СОВ/L7 также проходит полную обработку.
- Полная проверка раскрывает результаты только при активном IDPS **и** профиле СОВ, назначенном разрешающему правилу. На шестом пакете учебное событие выключает модуль, а на шестнадцатом снимает профиль с правила. Игрок должен восстановить соответствующую настройку.
- Верные путь и вердикт дают 100 XP. Пропуск атаки: −100 XP; ложная блокировка: −40 XP; неверный путь, неактивный IDPS или отсутствие профиля СОВ: −25 XP. Счёт не опускается ниже нуля. При нескольких ошибках используется самый серьёзный исход, штрафы не суммируются.
- Любая явная блокировка останавливает пакет. Ошибка маршрута при блокировке снижает очки, но не считается пропущенной атакой.
- На **десятой** пропущенной атаке смена завершается поражением. При обработке всех пакетов с меньшим числом пропусков смена завершена.
- Полностью верная блокировка открывает досье с описанием атаки, влиянием, мерами защиты, CVE (когда применимо) и ссылкой на NVD, OWASP или MITRE ATT&CK.
- Журнал хранит решения, коллекция — открытые досье. Рекорд сохраняется в браузере. Текущая смена сбрасывается после перезагрузки страницы или запуска новой смены.
- Пауза, справка и просмотр коллекции/журнала останавливают учебный таймер. Таймер информационный, без автоматического пропуска пакетов.
- Клавиши при фокусе вне кнопок/полей: `1` / `2` — путь, `A` / `B` — разрешить / блокировать (также `Ф` / `И`), `Enter` — следующий пакет. Все действия доступны мышью и на сенсорном экране.

## Источники и границы модели

Механика очереди запросов, решений и коллекции вдохновлена [Requests, Please](https://morronel.github.io/requests_please/) и описанием его [исходного репозитория](https://github.com/morronel/requests_please). Реальные атакующие запросы из проекта не переносились.

Официальные материалы UserGate, проверенные при реализации:

- [NGFW 7 Packet Flow](https://docs.usergate.com/usergate-ngfw-7-packet-flow_1569.html): точное название **FastPath**; исключения для фрагментированных пакетов и пакетов, предназначенных для СОВ/L7-инспекции. Обычный путь описан стадиями **Ingress → Policy processing → Egress**. «Полная проверка» в игре — учебное обозначение этого пути; термин FullPath в изученных материалах не подтверждён.
- [Система обнаружения и предотвращения вторжений, NGFW 7.x](https://docs.usergate.com/sistema-obnaruzheniya-i-predotvrasheniya-vtorzhenij_912.html): профиль СОВ назначается разрешающему правилу межсетевого экрана; для анализа нужен прямой и обратный поток.
- [Профили СОВ](https://docs.usergate.com/profili-sov_847.html): действия сигнатур — пропуск, отбрасывание, сброс соединения, блокировка адресов. Журналирование настраивается отдельно; обнаружение не равно блокировке.
- [Официальный логотип](https://docs.usergate.com/client/images/usergate.svg) используется без изменения в `src/assets/usergate.svg`. Знак и название принадлежат UserGate; игра не является официальным продуктом компании.

Сценарии явно отмечают, когда СОВ/L7 не требуется. Учебное правило для полной проверки направляет потоки на СОВ при включённом модуле и назначенном профиле. Игрок выполняет ручную классификацию и блокировку; реальная СОВ применяет действия сигнатур автоматически. Остановка модуля и снятие профиля — условные события смены, а не утверждение об обязательном поведении UserGate при обновлении.
Для сценариев HTTPS предполагается, что учебный шлюз может расшифровать поток согласно настроенному профилю. Само наличие TLS не означает возможность анализа содержимого настоящим IDPS. Сценарии содержат только синтетические метаданные и описания признаков. Приложение не отправляет пакеты, не сканирует узлы и не выполняет атаки. CVE приведены как обучающие примеры; класс атаки сам по себе не доказывает конкретную CVE.

## GitHub Pages

После включения Pages и успешного workflow игра будет доступна по адресу https://luciyvi.github.io/next-gen-firewell/.

Workflow `.github/workflows/deploy-pages.yml` запускает тесты, собирает `dist/` и публикует сайт при каждом push в `main`. Его можно запустить вручную через вкладку **Actions**. В **Settings → Pages → Source** должен быть выбран **GitHub Actions**. Используется встроенный `GITHUB_TOKEN`; отдельные ключи не нужны.

Vite использует относительный `base: './'`, поэтому ресурсы работают как в каталоге `/next-gen-firewell/`, так и при публикации на отдельном домене. Автономный экспорт также остаётся доступен через `npm run build:standalone`.

## Структура

- `src/App.tsx` — игровое рабочее место, пауза, журнал, коллекция, справка.
- `src/game.ts` — независимый движок подсчёта результатов.
- `src/scenarios.ts` — сценарии и карточки угроз.
- `src/styles.css` — адаптивный интерфейс, включая мобильные экраны и reduced motion.
- `src/game.test.ts` — тесты правил игры.
- `tests/e2e.mjs` — полный браузерный проход, поражение, IDPS/профиль СОВ, коллекция и адаптивность.
- `scripts/export-standalone.mjs` — экспорт автономного HTML.
- `tests/standalone.mjs` — проверка автономного HTML без сетевых запросов.
